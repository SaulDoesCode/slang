Kept per file, for runs on the machine and for builds.

    

    

  










  
sF1 or Escape closes

  

  

    
files

    
Ctrl+P the files: type to filter, Enter opens, a new name.s and Enter makes it · Ctrl+S save · Alt+W close the tab · Alt+PageUp / Alt+PageDown the tab before or after · a file changed on disk comes back when the tab has nothing unsaved

    
running

    
Ctrl+Enter run on the machine: what each line prints stands at its left, a failed check in red, an error marked at its word · Ctrl+Shift+Enter compile to Rust, build and run the binary; with fold on, what the program does before it first reaches outside (input, files, the shell, threads, the network, randomness, the arguments) is done at build time, and the output says how far · live runs after each edit · input has the arguments and stdin · Ctrl+R the Rust · Ctrl+` the console: s with the file's definitions

    
moving

    
F12 or Ctrl+click the definition of the word at the caret: in the file, in a file it loads (name.s.), or in std (read-only) · Alt+← back · Shift+F12 the uses · Ctrl+Shift+O the definitions of the file · Ctrl+G a line

    
finding

    
Ctrl+F find · F3 / Shift+F3 next, previous · Ctrl+H replace · Ctrl+Shift+F find in every file

  

  

    
writing

    
completion opens after two letters, or with Ctrl+Space: the file's definitions, the commands, std, the names in the file · Tab or Enter takes one, ↑ ↓ pick, Escape closes

    
resting the pointer on a word shows what it is: a command with its signature, a std word, a sigil, where it is defined · F2 the palette: click a word into the text, a sigil onto the word before the caret

    
Ctrl+= / Ctrl+− / Ctrl+0 text size · Ctrl+Z, Ctrl+Shift+Z, Ctrl+A, copy, cut, paste

    
zones and lanes

    
braces are zones, coloured by the word that takes them; braces shows them · middle-drag a range, the wheel picks what it becomes · middle-click a zone to unwrap or retype it

    
Ctrl+\ split into lanes · Alt+Enter add a lane · Alt+Backspace remove it · Ctrl+] merge · Ctrl+Shift+] join · Ctrl+L label · Ctrl+M fold lines into one · F6 the minted lines, editable

    
after a run each fork says how it ran, and each join shows its lanes
