moving

      
W A S D fly · Space C up, down · Q E roll · Shift fast

      
mouse looks while the cursor is captured; Tab frees or captures it; with it free, the right button drags the view

      
the wheel moves in and out along the view, which is the zoom; a sideways scroll moves sideways, Shift+wheel up and down · + - set the speed · Home back to the start · G to the definition of the word aimed at, or into the file a name.s. word loads · B back from there

      
pages

      
every paragraph of the file is a page; the file stays plain s, in page order

      
hold the left button on a page and look or move to carry it; the wheel while carrying pushes it nearer or further · Alt+wheel pushes the page aimed at

      
N a new page here, after the one aimed at · [ ] move the aimed page earlier or later in the file · Ctrl+L spreads every page out again

    

    

      
editing

      
double click a page, or aim and press Enter: it opens in the box below at that word; a click on the page moves the caret there

      
Tab completes the word · Esc ends the edit · a page left empty goes · a blank line splits a page in two

      
Ctrl+S saves (it also saves by itself) · Ctrl+Z outside the box undoes whole edits · Ctrl+O opens a file

      
running

      
F5 or Ctrl+Enter runs the file: what a word prints stands beside its line; an error marks its word · L runs again after every edit · ` shows the whole output

      
the box, when no page is open in it, runs s with the file's definitions · / searches, Enter or F3 goes to the next

      
Ctrl+B builds the file to Rust and a binary beside it; Ctrl+Shift+B writes only the .rs
