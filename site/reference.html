Reference

Every form, every name the machine sets, every command and the line each one takes.

Forms

The last character of a word, after at least one other, chooses its form. A word that is a command is the command, before any form.

formdoes
x~Pushes x (text, else number, else 404); a one-word value that runs, runs.
{~x~}Inside a brace: x's text, never run.
x`Sets x's text from the line (one value, or all joined with spaces).
x#Sets x's number from the first value, or 0.
x;Adds the first value, or 1, to x's number.
x:Subtracts the first value, or 1, from x's number.
x@Takes the last value off the line into x.
x$Defines the script x from the line's text; | reads as ~.
x.Calls x; with one value on the line, runs x that many times; last in a script, a tail call.
x..Calls x once, leaving the line to it.
form?Runs the form when ow is set.
form!Runs the form when ow is clear.
\wordThe command itself past any replacement; for any other word, the word as text.
⟨word⟩~A name that ends in a suffix character, used with any form.
:xA name that belongs to the running call.

Names the machine sets

nameholds
=Results of arithmetic, #l and #s, when no other name is given.
nThe round of &&&.
r rcThe output and exit code of <.
rnThe result of #prng and `prng.
$The item -l took.
errThe message of the last error a try, f or tcp caught, and of a thread command that failed.
eof1 once <_, _f or ?eof found the end, else 0.
outA worker's reply; a *** file's code to run.
threadsThe index of the last worker t started.
_The line <_ read, when no name is given.
args argcThe command line and its length.
port peerSet by tcp: the port a listener got, and the address it accepted.
?A new random 64-bit number on every read.

Commands

A command takes the values on the line in order, shown left to right; values in brackets may be left out. After a command the line is empty, except after (, ), ~, ## and <-, which work on the line itself.

Output

wordlinedoes
>v… >Prints a newline, then each value after a space.
>_v… >_Prints the values with nothing added.

Input, files, shell

wordlinedoes
<_[name] <_Reads a line of stdin into name, or _; sets eof.
wpath text wWrites the file.
+wpath text +wAppends to the file.
mva b mvMoves a to b.
rpath [name] rReads the file into name, or into the name spelled as the path.
r@path off len name r@Reads len bytes from offset off into name.
<cmd <Runs cmd in sh: output in r, exit code in rc.
fpath h mode [script] fOpens a handle: r, w, a, r+, w+ or a+.
f_h text [script] f_Writes the text and a newline.
_fh name _fReads a line into name; sets eof at the end.
+fh off name [script] +fWrites name's text at offset off.
@fh off len name @fReads len bytes at offset off into name.
?eofh ?eofSets eof for the handle.
f-h f-Closes the handle.

Names and numbers

wordlinedoes
nx name nSets name's number.
+ - * / ^a b [name] +Adds, subtracts, multiplies, divides, raises; into =, or name.
%a b [name] %The remainder of a by b, never negative for b > 0.
#prng[a [b [name]]] #prngA random number from 0 up to 1 into rn, or name; a and b set the seed first.
`prng[a [b [name]]] `prngThirty-two random letters, the same way.

Comparisons

wordlinedoes
= !=a b =ow: same value, different value.
==a b ==ow: equal as numbers.
<< >> <<= >>=a b <<ow: less, greater, at most, at least.
& ;a b &ow: still set and the same; still set and different.
!!!!Flips ow.

Lists and text

wordlinedoes
lv… xs lAppends each value to xs.
-lxs -lTakes the last item into $.
[l]xs i name [l]Item i into name; negative i from the end.
l=v xs i l=Sets item i.
l-xs l-Deletes the list.
#lxs [name] #lThe length into =, or name.
/ltext xs [sep] /lSplits at whitespace, at sep, or at {} into characters.
l/xs name [sep] l/Joins with spaces, or sep.
#stext [name] #sThe number of characters.

Code

wordlinedoes
><value 'word' ><The word runs the value as code from now on.
~text ~Runs the text.
?)table key [default] ?)Runs the code after key in the table of pairs, or default.
&&&count name &&&Runs the script count times, n holding the round.
//… //Consumes the line: a brace before it is a comment.
<-<-Returns from the running script.
<--[code] <--Ends the program with the exit code, 0 without one.
(… k (Keeps the last k values, puts the rest aside.
))Puts the values set aside back in front.
####Pushes the number of values on the line.

Threads and the network

wordlinedoes
tfile… tStarts a worker for each file.
<ttext i <tSends worker i a text to run.
>ti >tWaits for worker i's reply and runs it.
-ti -tCloses worker i.
***file… ***Runs the files side by side, then each file's out in order.
tcpaddr h mode [script] tcpc connects, s listens (sets port), a accepts on the listener named first (sets peer).

Lane words

worddoes
⟪a¦b⟫ … ⨝A fork of lanes a and b, joined at ⨝.
⟪xs…⟫One lane per item of xs, each starting with its item.
[[ || ]] ||>The same marks in ASCII.
collectEvery lane's line onto the line.
xs intoThe lanes' lines as the list xs.
i lane endlaneLane i's line, with its writes read first until endlane.
{code} reduceFolds the lanes' lines with code.
{code} lanewiseRuns code in each lane.
lanesThe number of lanes.
{body} {handler} tryRuns body; on an error, handler with the message in err.
