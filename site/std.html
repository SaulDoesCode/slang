Standard library

The library is written in s. Each word shows the line it takes and what it leaves, left to right, the top of the line last. std/all.s. loads core, line, text, math and check.

core

Stack words, line arithmetic, conditions, quotations, loops. Load it with std/core.s..

quotations: a brace literal is code waiting; ~ runs it on the line

wordline before → after
call… q → …

when… q → … : run q when ow
unless… q → … : run q unless ow

andp q → : ow = p and q, q tested only after p

keepx q → q(x) x

wordline before → after

while… c b → … : while c tests true run b
until… b c → … : run b, then again until c tests true
std/core.s.
3 4 swap >
2 3 add 4 mul >

check

wordline before → after

sh

Pipelines over lines of text: the line holds one value per text line, |> is a separator you can read along. Load it with std/sh.s..

wordline before → after
|>: separator, does nothing
~>: the same separator after a script body turns | into ~
catpath → line…
shcommand → its output lines
grepline… text → lines that contain text
grepvline… text → lines that do not
sedline… old new → each line with old as new
headline… n → first n
tailline… n → last n
wcline… → how many
uniqline… → without repeats next to each other
nlline… → numbered lines
shoutline… → each in capitals
putline… → : print one per line
>fileline… path → : write them to path
>>fileline… path → : append them to path
std/sh.s.
{echo one; echo two; echo one} sh |> uniq |> nl |> put
1  one
2  two
3  one
